MY RECOMP — ANDROID INSTALLABLE WEB APP

This is a Progressive Web App (PWA) bundle. It is designed for Android phones and includes:
- Food diary with calories, protein, carbs and fat
- Daily macro targets (starts at 1,700 kcal / 90g protein / 220g carbs / 51g fat)
- Weight, waist and hip measurements with a simple weight trend chart
- Workout log
- Export/import backup
- Offline support after first successful load

IMPORTANT INSTALL NOTE:
Android Chrome only offers a true PWA install when the app is served from a secure HTTPS website (or localhost). A ZIP file cannot install itself as an Android app. This bundle is ready to host on a static HTTPS host such as GitHub Pages or Netlify. After hosting:
1. Open the HTTPS website in Chrome on your Android phone.
2. Tap the three-dot menu.
3. Choose "Install app" or "Add to Home screen".
4. Confirm. The app icon will appear on your home screen.

DATA PRIVACY:
Entries are stored locally in the browser on that phone. They are not synced to an account. Use Settings > Export backup regularly. If you clear Chrome site data or change phones, restore from the exported JSON backup.

This package is a PWA, not a signed APK. Creating a signed APK requires Android build tooling and signing credentials.
